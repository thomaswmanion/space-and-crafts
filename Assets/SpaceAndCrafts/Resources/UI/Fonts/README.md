# Runtime UI font attribution

The `AtkinsonHyperlegible-Regular.otf` and `AtkinsonHyperlegible-Bold.otf` files are from the [official Google Fonts Atkinson Hyperlegible project](https://github.com/googlefonts/atkinson-hyperlegible).

Copyright 2020 Braille Institute of America. The typeface is licensed under the SIL Open Font License, Version 1.1; the complete license is included in `OFL-Atkinson-Hyperlegible.txt`.

`RuntimeUiFactory.Label` uses these static faces for runtime-created UI text and falls back to Unity's built-in font if the font assets are unavailable.
