# Quality Scorecard — Space & Crafts vs Super Mario Galaxy

> **Superseded for player-facing quality:** the current goal uses Super Mario Odyssey and four human quality categories. See [`ODYSSEY_SCORECARD.md`](ODYSSEY_SCORECARD.md). The historical values and checks below are automated repository-evidence proxies; they are not build/playthrough quality scores and do not establish parity.

**Benchmark:** Super Mario Galaxy (finished Nintendo 3D platformer, ~90–98 per pillar).  
**Parity gate:** every pillar ≥ **90**, Overall ≥ **90**, plus human Play Mode “feels smooth” sign-off.  
**Living scores:** updated by menu **Space & Crafts → Audit Quality Scorecard** → writes `Logs/quality-scorecard.json` + refreshes the table below.  
**History:** every audit appends one line to `Logs/quality-scorecard-history.jsonl` (overall + per-pillar) for easy iteration review.

---

## Review process (repeat every iteration)

1. **Bake** — If audio/anim banks are missing or stale: `SpaceAndCrafts.EditorTools.AuthoredAssetBakeMenu.Run`.  
2. **Audit** — Run `SpaceAndCrafts.EditorTools.QualityScorecardValidator.Run` (batchmode OK). Exit code `2` = parity not met.  
3. **Read** — Open this file + `Logs/quality-scorecard.json` (proxy scores + blockers). Diff vs previous line in `quality-scorecard-history.jsonl`.  
4. **Prioritize** — Always attack the **lowest 3 pillars** listed under Next focus (never cherry-pick easy wins).  
5. **Improve** — Ship one concrete raise per low pillar (content density, authored assets, feel polish).  
6. **Re-audit** — Re-run validator; confirm Δ in changelog + history JSONL.  
7. **Human gate** — For Controls / Camera / Overall: Play Mode in `PlayerPlayground` + Arrival; then run **Space & Crafts → Sign Off Human Feel (after Play Mode)** (writes `Logs/human-feel-signoff.json`). Validator never invents this.  
8. **Stop rule** — Goal complete only when **all pillars ≥ 90** and `humanFeelSignedOff = true`. Proxy-only “green” is **not** Galaxy parity.

### Scoring method

| Band | Meaning |
|---|---|
| 90–100 | Galaxy-class: commissioned finals + human feel sign-off |
| 71–88 | Strong authored stand-in banks (WAV/anim/FBX on disk); still shy of ship |
| 40–70 | Playable systems / organic or procedural-only |
| 0–39 | Prototype / missing pillar |

**Proxy ceiling:** automated audit awards up to **70** without on-disk authored banks, up to **88** once WAV/anim/FBX evidence exists. Scores **≥90** require **commissioned** finals **and** human feel sign-off.
